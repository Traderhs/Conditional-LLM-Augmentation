# Data redistribution notes

Third-party real texts are not redistributed in this package. The package publishes identifiers, hashes, split/manifold metadata, and synthetic outputs instead. This avoids assuming that a dataset paper, repository, or hosting page grants the same redistribution rights for every derived copy.

Main sentiment sources represented by the manifests:
- SST-2 (English)
- NSMC (Korean)
- CineXDrama (Bengali)
- HausaMovieReview (Hausa)
- DravidianCodeMix sentiment (Malayalam-English code-mixed)

Auxiliary offensive-language robustness sources represented by the manifests:
- OLID (English)
- KOLD (Korean)
- TB-OLID (Bengali)
- HausaHate (Hausa)
- DravidianCodeMix offensive-language data (Malayalam-English code-mixed)

Users should obtain the original datasets from the providers cited in the manuscript and comply with the providers' terms.
